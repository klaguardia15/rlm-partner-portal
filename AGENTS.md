# rlm-partner-portal

Partner Central sales-agreement call-off and configure-and-quote, plus a branding skill.

Read `README.md` first. To rebrand the portal from a logo and a primary image, follow `.cursor/skills/brand-partner-portal/SKILL.md`. Do not deploy Network metadata (`*.network-meta.xml`).

This package was extracted from a Revenue Cloud demo. It deploys onto an org that already has Revenue Cloud. It does not include the foundations CumulusCI project.
