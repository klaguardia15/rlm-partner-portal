# Worked example — Zebra

The branding skill does not ship these as the default theme. They show what the Zebra demo used.

| Token | Zebra value |
|---|---|
| Accent | `#A8F932` |
| Accent hover | `#96DC2C` |
| Header | `#000000` |
| On header | `#FFFFFF` |
| Font | IBM Plex Sans |

Logo files in `logo/` are the horizontal wordmark (color and white). The login background in the demo was a stripes image that is not in this repo; pass your own primary image to the skill.

Home hero copy from that demo is in `home-hero.html`.
